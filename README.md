# Space Fight 🚀

A 2D space-shooter game built with Python and Pygame. Pilot a spaceship, dodge incoming enemies, fire automatically, and earn points while protecting your health.

## ✨ Features

- Player-controlled spaceship
- Automatic projectile firing
- Multiple enemy spaceship sprites
- Scrolling space backgrounds
- Collision detection and explosions
- Five-point health display
- Score tracking and saved high score
- Game-over and restart functionality

## 🕹️ Controls

| Key | Action |
|---|---|
| Arrow Keys | Move the spaceship |
| Enter | Restart after game over |
| Automatic | Fire projectiles |

## 🛠️ Technologies Used

- Python
- Pygame

## 🚀 How to Run

1. Install Python 3.
2. Install Pygame:

   ```bash
   python -m pip install pygame
   ```

3. Open a terminal in the folder containing `Space Fight.py` and run:

   ```bash
   python "Space Fight.py"
   ```

## 📁 Project Structure

- `Space Fight.py` — Main game file
- `gallery/` — Backgrounds, spaceship sprites, effects, and other assets

The Python file and assets are inside the nested `Space-Fight-main/` directory in the supplied archive. Keep the asset folder in its expected location.
